# Finetuning Overview

- **SFT CoT Warmup** (`docs/sft.md`): boots the model into the `<think>...</think>` format by training on a prebuilt SFT mix dataset (CoT + plain games) generated by `scripts/data/preprocess.py`. It guarantees the tokenizer, data layout, and reasoning tokens are already stable before RL.
- **GRPO Phase** (`docs/grpo.md`): takes the warmed-up checkpoint, generates reasoning rollouts per prompt, and applies the PPO-style loss with structured rewards so reasoning tokens become a controllable policy lever.

Together they form a two-stage finetuning stack: first mold syntax and short-term planning, then reward emergent reasoning with a dense, interpretable reward function.
